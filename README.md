# Controla Fácil 💰

Um sistema web simples e intuitivo focado em ajudar na organização das suas finanças pessoais. Ele conta com um painel de controle (dashboard) fácil de usar para registrar entradas (receitas) e saídas (despesas), além de acompanhar o saldo atual e o histórico de transações.
